# 지도 데이터

- 출처: https://github.com/datasets/geo-countries
- 원본: https://raw.githubusercontent.com/datasets/geo-countries/master/data/countries.geojson
- 기반: Natural Earth (public domain), https://www.naturalearthdata.com/about/terms-of-use/
- 2026-09-15 다운로드. mapshaper `-simplify 3% keep-shapes`, 좌표 소수 둘째 자리로 경량화.
- 국가 이름은 ISO 코드와 브라우저 Intl.DisplayNames(한국어)로 표시합니다.
- 국가/지역 경계는 교육용 참고 자료이며 영유권을 판단하는 자료가 아닙니다.
